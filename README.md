# 宝宝奶粉用量登记（Baby Milk Log）

面向手机端日常使用的在线奶粉用量登记网页，支持两种便捷语音录入方式，数据实时同步至云端数据库：

1. **页面内一键说话**：点击页面大麦克风按钮直接说话，后端通过火山引擎豆包流式语音识别 2.0 自动转文字并提取日期、喂奶时间与毫升数。
2. **手机自带语音转文字 / 文本输入**：在输入框使用手机键盘自带语音转文字或手动输入，后端通过 DeepSeek V4.1 Flash 自动解析并写入喂奶记录表。
3. **独立统计页面（统计 Tab）**：点击顶部「统计」按钮进入独立统计视图，查看 **本周日均奶量与每日柱状图**、**每 5 日标准周期日均奶量** 以及 **每月日均奶量与月度汇总**，并支持切换「含今日 / 不含今日」统计口径。
